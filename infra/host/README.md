# Настройки хоста (VPS), которые не живут в Docker

Всё, что здесь лежит, настраивается **на самом сервере**, а не в контейнерах: Coolify и
docker-compose до этого уровня не дотягиваются. Файлы хранятся в репозитории, чтобы настройка
не была устной легендой и переживала пересоздание сервера.

## MSS clamping — обход чёрной дыры PMTU

**Что чинит.** У части пользователей Mini App показывал пустой белый экран, а в логах бэкенда
их не было вовсе. Причина: на пути к клиенту MTU меньше 1500, ICMP «нужна фрагментация» до
сервера не доходит, и сервер ретрансмиттит полноразмерные пакеты до таймаута клиента.
Подпись беды: `index.html` (сотни байт) открывается за 80 мс, а бандл (700 КБ) и картинки
висят до таймаута. Разбор инцидента 2026-08-02/03 — `docs/modules/infrastructure.md`
§ «MSS clamping».

**Почему юнит, а не `iptables-persistent`.** Тот сохраняет и восстанавливает дамп *всех* правил,
включая цепочки Docker, который создаёт их сам при старте — восстановление такого дампа
конфликтует с докером. Наш юнит трогает ровно два своих правила в таблице `mangle`.

**Почему `--set-mss 1200`, а не `--clamp-mss-to-pmtu`.** Клампинг по PMTU опирается на тот самый
ICMP, который до нас не доходит. 1200 подобрано эмпирически и подтверждено диагностикой на
живом клиенте (столько же берёт QUIC у Cloudflare, который такие дыры обходит по умолчанию).

### Установка (один раз на сервер)

```bash
scp infra/host/clubs-mss-clamp.sh infra/host/clubs-mss-clamp.service \
    infra/host/install-mss-clamp.sh root@77.42.23.177:/tmp/
ssh root@77.42.23.177 "cd /tmp && sh install-mss-clamp.sh"
```

### Проверка

```bash
ssh root@77.42.23.177 "/usr/local/sbin/clubs-mss-clamp status"
```

Обе строки должны быть `OK`. После перезагрузки сервера — та же команда: юнит поднимает правила
сам, вручную ничего делать не нужно.

### Если правил нет прямо сейчас (сервер перезагрузили до установки юнита)

```bash
ssh root@77.42.23.177 "systemctl start clubs-mss-clamp"
```

или, если юнит ещё не поставлен, — те же два правила руками:

```bash
ssh root@77.42.23.177 "iptables -t mangle -A FORWARD -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --set-mss 1200 && iptables -t mangle -A POSTROUTING -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --set-mss 1200"
```

### Снять

```bash
ssh root@77.42.23.177 "systemctl disable --now clubs-mss-clamp"
```

`ExecStop` уберёт правила из ядра — перезагрузка не потребуется.
