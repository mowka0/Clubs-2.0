# Биллинг за чат — тест-план staging-прогона

**Дата:** 2026-09-16. **Спека:** `platform-billing.md` (критерии — § 10). **Модель:** 15 дней
бесплатно от первой созданной встречи (`BILLING_TRIAL_DAYS`), дальше 199 ₽/мес; на прогоне период
ужат до суток. Провайдер — заглушка (`BILLING_PROVIDER=stub`): страница «оплаты» сама спрашивает
исход — карта, СБП или отказ. Роли: **PO** — руками с телефона; **Dev** — БД staging, логи,
сдвиг дат, чтобы не ждать сутки.

## 0. Подготовка

**P1. Переменные у staging в Coolify** (после правки — Redeploy):

| Переменная | Значение | Зачем |
|---|---|---|
| `BILLING_PROVIDER` | `stub` | без неё бэкенд не стартует |
| `BILLING_RECIPIENT_NAME` | `Варламов Иван Михайлович` | ФИО в шите и оферте |
| `BILLING_TRIAL_DAYS` | `1` | бесплатный период за сутки |
| `SUBSCRIPTION_PERIOD_DAYS` | `1` | оплаченный период за сутки |
| `SUBSCRIPTION_LIFECYCLE_CRON` | `0 */5 * * * *` | напоминания, списания, PAST_DUE каждые 5 минут |
| `BILLING_RECONCILE_CRON` | `0 */5 * * * *` | опрос заглушки: без него дочернее списание «висит» до часового тика |
| `BILLING_PENDING_TIMEOUT_HOURS` | `0` | опрашивать счета сразу, не через 6 часов |

**P2. Клубы на staging** (состояние на 16.09, строк бесплатного периода ни у кого нет):

| Клуб | Роль в прогоне |
|---|---|
| Корги 🫶 (0 встреч) | основной: период → стена → карта → автосписание → кик бота |
| Пробник 2 (0 встреч) | оплата заранее по СБП → напоминания без автопродления → грейс → стена → повторная оплата |
| тест_оплаты_полный (16 встреч) | «старый клуб получает полный период с первой новой встречи» → переподключение чата |
| Партия (119 встреч) | не трогаем |

**P3.** Второй аккаунт с правом создавать встречи (TC-13) — по желанию. Личка с ботом staging
открыта (DM приходят туда).

Формат кейса: **Шаги** → **Ожидаю** → *Dev проверяет* (что смотрю в БД/логах).

## Известные ограничения прогона

- При суточных периодах напоминания «за неделю» (бесплатный период) и «за 3 дня» (подписка) не
  увидеть — только «за день». Их логика покрыта юнит-тестами.
- Настоящее списание Robokassa на staging не проверяется: рекуррент у неё без тестового режима.
  На проде — служебный `charge-now` (спека § 11) на чате PO, один раз.
- Сообщения бота после кика остаются в чате — ограничение Telegram.
