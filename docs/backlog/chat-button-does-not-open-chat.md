# БАГ: кнопка «💬 В чат» на странице клуба не открывает чат (прод)

**Статус:** исправлено, ждёт проверки на staging · **Severity: MEDIUM** (единственная точка входа
в чат из приложения мертва для тех, кто пришёл из этого же чата) · **Создано:** 2026-08-11,
репорт PO с прода · **Причина найдена:** 2026-08-12 · **Ветка фикса:** `bugfix/chat-button-open`.

## Симптом (слова PO)

> Нажимаю [пилюлю «💬 В чат» на странице клуба], происходит вибрация, вроде начинает открываться
> снизу экрана что-то, но моментально сворачивается и ничего не происходит.

Ошибки Telegram («Ссылка недействительна» и т.п.) PO **не видит** — шторка схлопывается молча.

## Решающая улика (2026-08-12)

PO уточнил, что баг зависит от точки входа в приложение — и это сняло все прежние гипотезы:

| Как открыто приложение | Кнопка «В чат» |
|---|---|
| из лички с ботом | работает, Telegram переключает на чат клуба |
| кнопкой из чата клуба («Открыть клуб», закреп встречи) | мигание, остаёшься в приложении |

Один и тот же человек, тот же клуб, та же ссылка. Отличается только источник запуска.

## Причина

Кнопки в группе — url-ссылки `t.me/<bot>?startapp=club_…` / `event_…`
(`ChatLinkService.kt:304`, `LivePinRenderer.kt:40`). Telegram открывает Mini App **поверх того
самого чата**, из которого нажали. Кнопка «В чат» просит открыть чат клуба — то есть ровно тот
экран, что уже лежит под приложением. Переходить некуда: клиент дёргается (это и есть «мигание»)
и возвращается, а Mini App не закрывается — `openTelegramLink` (`web_app_open_tg_link`) в
современных клиентах его больше не закрывает.

Из лички всё работало, потому что чат клуба там — другой экран.

**Корень:** «перейти в чат» реализовано только как «открой ссылку», хотя когда чат уже под нами,
нужного результата достигает противоположное действие — закрыть приложение.

## Что сделано

`utils/telegramLinks.ts` → `openChatLink(url)`: открывает ссылку как раньше, а затем закрывает
Mini App, **если запуск был из группового чата**. Признак — launch-параметр `chat_type`
(`isLaunchedFromGroupChat` в `telegram/sdk.ts`); Telegram отдаёт его только для запусков по direct
link, то есть ровно для наших `startapp`-кнопок, а для лички там `sender`/`private`.

Ссылка открывается всегда и первой: из чата клуба А кнопка на странице клуба Б должна открыть
чат Б — это другой экран, и Telegram на него переключится (проверено PO до фикса, этот путь
работал и ломать его нельзя). Из лички поведение не изменилось вовсе.

Цена, принятая осознанно: при заходе из группы приложение после перехода закрывается, а не
остаётся свёрнутым. Мы не знаем, тот ли это чат — `chat_instance` из launch-параметров с нашим
`chat_id` не сопоставляется.

Тесты: `frontend/src/test/utils/telegramLinks.test.ts` (8 шт.) — группа/личка/без чата-источника,
порядок «ссылка → закрытие», нативный фолбэк, и что `openTmeLink` (пикер «привязать бота»)
приложение не закрывает.

## Отвергнутые гипотезы (не переоткрывать)

1. **«Invite-ссылка — приглашение вступить, для участника пустышка».** Была главной до
   2026-08-12. Опровергнута: из лички человек тоже уже участник, и там кнопка работает.
2. **Ссылка отозвана / протухла.** Та же ссылка работает из лички.
3. **Полноэкранный режим.** Одинаков в обоих сценариях — платформа-то одна.
4. **Упали в `window.open`.** Не объясняет зависимость от точки входа.
