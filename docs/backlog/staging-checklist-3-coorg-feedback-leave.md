## G2. «+» у со-организатора и у участника

- **Кто:** B, потом C.
- **Шаги:** B нажимает «+» в доке. Потом то же у C.
- **Ожидаемо:** у B пункты **«Встреча»**, **«Сбор»**, **«Сообщить о проблеме»**. У C — только
  **«Сообщить о проблеме»**.

## G3. «Управление» у со-организатора

- **Кто:** B.
- **Шаги:** страница клуба → шестерёнка → «Управление».
- **Ожидаемо:**
  - табы **«Настройки · Статистика»** — ни «Чата», ни «Финансов»;
  - полоска подписки вверху «Управления», **без ползунка автосписания**;
  - на странице клуба полоска появляется, только когда пора платить (на staging — за ≤ 7 дней до
    конца периода, а период там 1 день, так что может висеть почти всегда).

## K1. Сообщить о проблеме

- **Кто:** C; проверяет B.
- **Шаги:** C: «+» → «Сообщить о проблеме» → текст «что-то сломалось» → «Отправить».
- **Ожидаемо:** у C тост **«Спасибо! Сообщение отправлено»**. B (саппорт) получил в личку сообщение
  с текстом, именем C, его @username и экраном, откуда отправлено.

## J1. C выходит из клуба

- **Кто:** C.
- **Шаги:** обложка клуба → «Выйти из клуба» → «Выйти».
- **Ожидаемо:**
  - шторка **«Выйти из клуба?»** с текстом **«Доступ к клубу будет отозван сразу. Вы будете удалены из
    всех активных встреч и сборов.»** (если C записан на встречу — ещё предупреждение про обязательства);
  - после «Выйти» — экран «Мои клубы», тост **«Вы вышли из клуба «Тест Clubs»»**;
  - C **остаётся** в Telegram-группе.

## J2. A удаляет C из клуба

- **Кто:** A, проверяет C.
- **Шаги:** позвать C снова (ссылкой «Пригласить в клуб», C вступает). Затем A: «Участники» → C →
  «Удалить из клуба» → причина «тест» → подтвердить.
- **Ожидаемо:** C в личке: **«Организатор удалил вас из клуба «Тест Clubs». Причина: тест»**.

## J3. Отвязать чат

- **Кто:** A.
- **Шаги:** «Управление» → «Чат» → «Отвязать чат» → «Отвязать».
- **Ожидаемо:** тост **«Чат отвязан»**; бот вышел из группы; закреп клуба в группе удалён; клуб
  остался, на его странице панель **«Подключи чат клуба»**.
