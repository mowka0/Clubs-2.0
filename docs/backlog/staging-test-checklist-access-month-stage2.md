## A. Взнос продлевает доступ на календарный месяц

- [ ] **A1.** Организатор жмёт «Взнос получен» участнику платного клуба (`MEMBERSHIP_ACCESS_PERIOD_DAYS=0`)
      → доступ открыт, дата «до» = **то же число следующего месяца** (28 июня → 28 июля), а не +30 дней.
- [ ] **A2.** Участник видит ту же дату у себя (страница клуба / «Мои клубы») — фронт и бэк совпадают.
- [ ] **A3.** Пограничный случай: выдать доступ 31-го (или подставить `access_until` на 31 января в БД)
      → следующий период = **последний день февраля**; цепочка НЕ возвращается к 31-му (решение PO, предупреждён).
- [ ] **A4.** `MEMBERSHIP_ACCESS_PERIOD_DAYS=3` → продление на 3 дня (staging-ужимка жива).
