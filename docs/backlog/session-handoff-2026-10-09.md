## 6. Ловушки сессии

- **Деплой падал на `RUN apk add --no-cache curl`** (exit 1) — сбой зеркала Alpine, не код. Лог:
  `select logs from application_deployment_queues where id = …` (JSON); лечение —
  `gh run rerun <id>` воркфлоу «Deploy Preview Branch to Staging».
- **Staging один на все ветки** — пуш другой ветки (даже хэндоффа от master) затирает staging.
  Хэндофф поэтому в той же ветке.
- **Не пушить мелкие доки посреди проверки PO** — пуш пересобирает staging (~4 мин).
- **Нативная кнопка Telegram одна** — не прятать её из отдельного хука; только через счётчик
  `useBackButton` (иначе снова «Закрыть» вместо «Назад»).
- **Фото встречи бот шлёт в Telegram ссылкой** (`sendPhoto`) — поэтому обложка и фото после сжатия
  JPEG, не WebP. Проверка на устройстве ещё не сделана (D).
- **vitest иногда роняет файл целиком** при параллельном прогоне (`tldts`, `startTests`) — по
  отдельности проходит; перезапуск даёт зелёный.
- **Предпросмотр браузера не исполняет JS у файлов вне проекта** — проверочные страницы класть во
  `frontend/public/` или временный `frontend/__harness.html` и удалять после.
