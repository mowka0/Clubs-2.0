  PENDING материнских счетов (`SELECT count(*) FROM platform_payment WHERE kind='MOTHER' AND

## 6. Ловушки сессии

- **Хук `useBackButton` монтируется дважды** (Layout + страница) — любое новое действие в нём
  должно идти через `claimPress`, иначе сработает два раза.
- **`<button>` внутри `<label>`** получает accessible name от label — ссылка в чекбоксе вынесена из
  label, у `<input>` `aria-label` с полным текстом.
- **Recraft пуст (0 кредитов)**, `pip install realesrgan` ломается на `basicsr` — см. § 5.
- **Кромка стикера в 1800 px — всего ~5 px**: сужение маски на 5 px её «съедает» и находит бумагу;
  две первые попытки испортили лист нот. Проверять вырезку крупным планом до пуша.
- **Браузер пане:** `zoom` по региону не поддерживается; `file://` отдаёт снимок без картинок —
  HTML-мокап с картинками открывать через статический сервер в `.claude/launch.json`
  (`python3 -m http.server 5181 --directory docs/design`; конфиг в этой сессии откачен).
- **Staging-стаб:** подтверждать дочерний счёт через `/api/billing/stub/pay`, не ждать :15; не
  передеплоивать между списанием и подтверждением.
- **PayButton** в `payment_method` у обоих боевых платежей — см. § 2.
- Полный `npx vitest run` иногда валит случайный файл на загрузке модуля (известно); изолированно зелёный.
