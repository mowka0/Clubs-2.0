# Прогон форматов встреч v2 (V86) на staging

> Составлено 2026-09-02 после реализации V86 в ветке `feature/roster-threshold`. Заменяет
> `party-club-staging-testplan.md` (V85: форматы min/max, в прод не выходили) и
> `event-formats-test-cases.md` (там же). Спека — `docs/modules/event-formats.md`, критерии
> приёмки — её § 13 (AC-1…AC-17); здесь — как проверить их руками за один вечер.

## 0. Подготовка

1. **Env на staging (Coolify)** — к прежним значениям (`STAGE2_TRIGGER_MINUTES_BEFORE=10`,
   `STAGE2_POLL_MS=20000`, `LATE_DECLINE_THRESHOLD_MINUTES=60`, окна явки 5 минут) добавить
   **`ROSTER_WARNING_MINUTES_BEFORE_DEADLINE=3`**. Без неё правило ② сработает за 3 часа до
   дедлайна, то есть при 10-минутном интервале набора — сразу при создании («израсходовано»,
   DM не будет). Редеплой после смены env обязателен.
2. После деплоя ветки — в БД staging (`flyway_schema_history`) версия `86` с `success = true`;
   у `events` есть `min_participants`, `roster_decided_at`, `roster_warning_sent_at`, нет `limit_kind`.
3. Старые встречи «Партии» (были `max`) на карточках и в шапке читаются «👥 ДО N», открытые —
   «🌊 ОТКРЫТАЯ» (AC-13). Шаблоны клуба: бывшие `max` — без минимума (AC-14).
4. Инструмент ускорения — `~/clubs-fast.sh` (`show` / `early` / `late`), правит последнюю
   созданную встречу клуба; имя контейнера Postgres добывать подстановкой при каждом обращении
   (см. `event-formats-session-handoff.md` § 6–7).

Роли: **О** — организатор (создатель встречи), **У1…У3** — участники, **Ч** — чат клуба с живым
закрепом. Кроме ТК-G все кейсы — на встрече с датой через ~15 минут и интервалом по умолчанию
(10 минут): дедлайн через ~5 минут, предупреждение ② — через ~2.

## 2. Набор с минимумом: правила ② и ① (AC-3, AC-4, AC-10, AC-15, AC-16)

Встреча: максимум 4, минимум 3, дата через 15 минут. О — не голосует (AC-16: создатель без
голоса не в составе и не в счётчике).

|---|---|---|
| B1 | У1 «Иду» | полоса «Нужно ещё 2 человека · Набор закрывается … — если не наберём, встреча отменится»; кольцо 1/4 с засечкой на 3; закреп «👥 Собрались 1 из 3–4 — нужно ещё 2. ⏳ Набор закрывается … Не наберём — встреча отменится.» |
| B2 | О открывает встречу | таб «Без ответа (N)» виден **на наборе**; У1 в нём нет, У2 с «Возможно» — есть, О — нет; «Напомнить всем» |
| B3 | Напомнить У2 | DM У2: «🔔 Организатор ждёт ответа … Проголосуйте — набор закрывается …», кнопка «Открыть встречу»; повтор — 0 |

| B5 | Нажать кнопку ② | alert «Напомнили N» (У2 уже напомнили → он не считается) или «Напоминать некому»; второй тап — «Напоминать некому» |
| B6 | Ничего не делать до дедлайна | **правило ①**: встреча отменена, причина «Не набрали 3 участников к закрытию набора»; пост в Ч, DM участникам, закреп «отменена» |
| B7 | Повторить B1 с У1+У2+У3 «Иду» до дедлайна | полоса «Минимум набран · свободно 1 место · Набор закрывается …»; закреп «👥 Собрались 3 из 3–4 — минимум набран, свободно 1.»; ② в этот раз **не приходит** (минимум набран в момент ②) |
| B8 | Дедлайн | «Состав собран — встреча состоится», DM составу, закреп «✅ Состав собран: 3 из 4.» |
| B9 | После закрытия О напоминает У2 (если он остался без места) | напоминание уходит **второй раз** (одно на этап), текст с «✓ Подтвердить участие» |
