Удалены как мёртвые: `STAGE2_DECLINE_CUTOFF_MINUTES` (переименована), `ROSTER_SHORTFALL_POLL_MS`

(бесплатно с заменой, −100 без), «поздний» после `T−5` (−50 / −150), автоотмена при молчании
организатора в `T−5`.

## Найденное и исправленное по ходу теста

1. Голос «Иду» писал место в составе, и участник пропадал из вкладки «Идут», а кнопка голоса
   переставала подсвечиваться. Теперь на наборе наружу отдаётся голос, место — отдельным полем
   `seat` (и в `/my-vote`, и в `/responses`).
2. Отказ внутри порога был недоступен из интерфейса — фронт прятал кнопку по удалённому теперь
   `confirmedDeclineDeadline`. Самый дорогой сценарий был непроходим.
3. Закрытый, но неполный состав обещал «встреча состоится». Теперь: «Состав закрыт, но неполный —
   N из M · Организатор решит, состоится ли встреча».
4. Состав мог распасться после закрытия молча. Теперь оргу уходит DM «Состав стал неполным»
   с кнопками «Открыть встречу» и «🔔 Позвать (N)» — ровно один раз, на пересечении порога вниз.

## Открытые наблюдения (не блокеры фичи)

1. **Чат «Опат»: `live_pin_enabled = false`** — поэтому в чат не приходят посты о встречах и не
   работает живой закреп. Тумблер включается в приложении; без него сценарий закрепа не проверить.
2. **Кнопка «Открыть клуб» из закрепа** приводит на «Мои клубы». Ссылка в сообщении корректная
   (`?startapp=club_7ab34ae8-…`, клуб активен), Main Mini App у бота настроен. Похоже на
   переиспользование уже открытого Mini App — параметр приходит только при холодном старте.
   Требует проверки «закрыть приложение → нажать кнопку»; к порогу набора отношения не имеет.
3. **Ярлык `expired_no_confirm` = «Не подтвердил»** для формата 🎟 читается неточно: подтверждать
   там нечего, человек просто не попал в состав. Правка на две строки, PO пока не заказывал.
4. У владельца много членств в удалённых клубах — «Мои клубы» сыпет 404 в логи. Старый мусор.
