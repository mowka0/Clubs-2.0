## 5. Ловушки сессии

- **Документация Robokassa** с этой машины не открывается (ни WebFetch, ни curl), но открывается
  **с VPS**: `ssh root@77.42.23.177 'curl -s https://docs.robokassa.ru/ru/<страница>'`. Сайт — SPA,
  карта страниц в `sitemap.xml` (`notifications-and-redirects`, `recurring-payments`, `xml-interfaces`).
- **Узнать, чем на самом деле платили** — `OpStateExt` с VPS, пароль не покидает сервер:
  подпись `sha256(MerchantLogin:InvoiceID:ROBOKASSA_PASSWORD_2)` из env прод-контейнера, ответ
  `IncCurrLabel` и `PaymentMethod/Code`. Переменная — `ROBOKASSA_PASSWORD_2` (с подчёркиванием).
- **`charge-now` без JWT PO не вызвать** (кнопки во фронте нет). Быстрее — календарный тик: конец
  периода в прошлое + временный крон `0 */2 * * * *` в Coolify + Redeploy. Повторы защищены
  (напоминания по ключу события, списание — `hasPendingRecurring`), частый крон на проде безопасен.
- **Кнопка «Продлить» есть только в «закончилась»**: у оплаченного клуба (ACTIVE) полоска без
  кнопки — для теста оплаты клуб переводится в PAST_DUE с концом периода в прошлом.
- **Тесты фронта, которым нужен Node `fs`** — класть вне `src` (`frontend/checks/`): типов Node в
  сборке нет, `tsc` проверяет `src` и падает. Под Vitest CSS через `?raw` приходит пустым.
  На этом упала одна сборка staging (`f35a4392`) — следующий коммит её закрыл.
- **Coolify:** значение переменной вписывать, не очищать (пустая строка роняет шедулер); после
  мержа не пушить, пока прод не поднялся; очередь —
  `docker exec coolify-db psql -U coolify -d coolify -Atc "select id,status,left(commit,8) from application_deployment_queues order by id desc limit 3"`.
- Остальные ловушки (док и «назад», `NewClubFromChatGate`, две `Modal`, zsh nomatch) — вечерний
  хэндофф § 6.
