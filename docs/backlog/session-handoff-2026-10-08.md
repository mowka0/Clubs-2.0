## 5. Рецепты Dev

**Очистка staging** — дамп → всё, кроме справочников → рестарт. SQL:

```sql
DO $$ DECLARE t text; BEGIN
  SELECT string_agg(format('%I', tablename), ', ') INTO t FROM pg_tables
  WHERE schemaname = 'public'
    AND tablename NOT IN ('cities', 'interests', 'subscription_pricing', 'flyway_schema_history');
  EXECUTE 'TRUNCATE ' || t || ' CASCADE';
END $$;
```

Порядок: `pg_dump | gzip` в `/root/backups/` → файл на VPS (`scp`) → `docker cp` в postgres-контейнер
→ psql с файлом (heredoc в `docker exec` без `-i` до psql молча не доходит) → `redis-cli flushdb` →
`docker restart` бэкенда. Дамп до очистки: `/root/backups/staging-before-wipe-20261008-0839.sql.gz`.

**Сброс туров онбординга:** `DELETE FROM user_onboarding_tours WHERE user_id = … AND tour_key IN (…)`.

**Сдвиги для блока I:** `chat_trial.started_at` −2 дня (стена), `service_subscription.current_period_end`
= сейчас −1 мин (продление), −8 дней (конец льготы).

**Бот выходит из группы:** Telegram API с VPS, токен из env бэкенда (`unpinChatMessage`, `leaveChat`);
при пачке запросов — «Too Many Requests: retry after N».

## 6. Ловушки сессии

- **Заглушка оплаты хранит дочерние списания в памяти** — redeploy staging между тиком и опросом
  оставляет счёт `PENDING` навсегда; лечение: счёт → `FAILED`, `charge_attempts = 0`.
- **`BILLING_RECONCILE_CRON` на staging был часовым** — PO выставил `0 */5 * * * *`.
- **Субагенты на основной модели падали с 403** — ревью и исследование шли с `model: sonnet`.
- **`mergeable_state: unknown` после мержа соседнего PR** — лечится пушем в ветку (подтянуть основную).
- **Обязательная проверка Gitleaks** на свежем коммите: мерж PR отказывает, пока она идёт — ждать,
  админ-обход не использовать.
- **Хук безопасности** ложно ловит «force push в основную ветку», если в одной команде с git push
  оказывается текст со словами про основную ветку и флагом `-f` (например, хэндофф в heredoc) —
  писать файл отдельно, git отдельно.
- **Палитровый PNG (256 цветов)** даёт зерно и весит меньше WebP; полноцветный арт — в WebP.
- **Форма встречи** не даёт старт ближе срока «передумать бесплатно» (18 ч, ползунком от 6 ч) — на
  staging встречу «через 15 минут» делать через «Редактировать».
- Очередь деплоев Coolify: `docker exec coolify-db psql -U coolify -d coolify -Atc "select id,status,left(commit,8),application_id from application_deployment_queues order by id desc limit 3"`.
